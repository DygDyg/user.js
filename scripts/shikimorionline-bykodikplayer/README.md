# Shikimori Online by kodik player

Добавляет кодик плеер на шикимори

- **Версия:** 0.2
- **Автор:** ДугДуг
- **Категория:** Видео и плееры
- **Сайты:** `shikimori.one`

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`shikimorionline-bykodikplayer.user.js`](./shikimorionline-bykodikplayer.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
