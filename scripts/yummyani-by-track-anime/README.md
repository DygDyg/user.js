# yummyani by track-anime

Добавляет кнопку на track-anime.dygdyg.ru на сайт yummyani.me

- **Версия:** 2025-08-02
- **Категория:** Аниме
- **Сайты:** `site.yummyani.me`

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`yummyani-by-track-anime.user.js`](./yummyani-by-track-anime.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
