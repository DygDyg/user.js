# Anistar редирект

Автоматически переключает со старого адреса anistar.appspot.com на актуальный.

- **Версия:** 0.7
- **Автор:** ДугДуг
- **Категория:** Утилиты
- **Сайты:** `anistar.appspot.com`

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`anistar-redirect.user.js`](./anistar-redirect.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
