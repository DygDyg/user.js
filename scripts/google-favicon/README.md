# Google Favicons

## Назначение

Добавляет значки сайтов к результатам поиска Google, чтобы было проще узнавать источники.


- **Версия:** 1.1
- **Категория:** Поиск
- **Сайты:** `www.google.`

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`google-favicon.user.js`](./google-favicon.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
