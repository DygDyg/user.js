# PoEAutoTrade

Производит автопокупку товара в "живом поиске" на PoE Trade

- **Версия:** 0.7
- **Автор:** ДугДуг
- **Категория:** Игры
- **Сайты:** `ru.pathofexile.com`, `www.pathofexile.com`

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`poeautotrade.user.js`](./poeautotrade.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
