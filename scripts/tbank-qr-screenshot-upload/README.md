# TBank QR Screenshot Upload (v5)

## Назначение

Добавляет на страницу сканирования QR-кода Т-Банка кнопку захвата выбранного окна и вставки изображения в форму.


- **Версия:** 1.5
- **Автор:** ДугДуг
- **Автор в оригинальных метаданных:** не указан
- **Источник:** резервная копия Tampermonkey от 26 октября 2026 г.
- **Сайты/шаблоны:** `https://www.tbank-online.com/*`

[Установить userscript](https://raw.githubusercontent.com/DygDyg/user.js/main/scripts/tbank-qr-screenshot-upload/tbank-qr-screenshot-upload.user.js)

> Перенесено из резервной копии без проверки работоспособности на актуальных версиях сайтов. Автор для каталога изменён на ДугДуг; сведения об исходном авторе указаны выше. Ссылки обновления указывают на UserJS Hub.
