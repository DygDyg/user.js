# Антилах

Блокирует залипание интерфейса: перехват Ctrl+Win и Shift+Win на любом сайте.

- **Версия:** 2.1.8
- **Автор:** ДугДуг
- **Категория:** Утилиты
- **Действует на всех сайтах**

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`antilah.user.js`](./antilah.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
