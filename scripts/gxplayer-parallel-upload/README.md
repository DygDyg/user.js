# GXPlayer Parallel Upload

## Назначение

Добавляет на страницу загрузки GXPlayer очередь параллельной отправки файлов с настройкой потоков, прогрессом, повторами и уведомлением о завершении.

**Автор:** ДугДуг

Пользовательский скрипт для загрузки видео на [GXPlayer](https://gxplayer.xyz/users/upload.php) через Tampermonkey или Violentmonkey.

**Версия:** 2.11  
**Сайт:** `gxplayer.xyz/users/upload.php`

## Возможности

- Параллельная загрузка нескольких видео с регулируемым числом потоков.
- Автоматический подбор количества потоков по общей скорости или ручное управление (1–20).
- Прогресс, суммарная скорость, ETA, статистика загруженных файлов и ошибок.
- Повтор неудачных загрузок, включая «Повторить все» с интервалом 1 секунда.
- Переключатель скрытия/показа успешно загруженных файлов.
- Звуковое оповещение после завершения очереди.

## Установка

[Установить скрипт](https://raw.githubusercontent.com/DygDyg/user.js/main/scripts/gxplayer-parallel-upload/gxplayer-parallel-upload.user.js)

Откройте ссылку с установленным Tampermonkey или Violentmonkey и подтвердите установку. Редактировать скрипт можно через менеджер расширения. В метаданных настроены `@updateURL` и `@downloadURL` на этот репозиторий.
