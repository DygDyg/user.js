# Dark VK Theme

## Назначение

Добавляет тёмное оформление ВКонтакте с пользовательскими настройками темы и элементов интерфейса.


- **Версия:** 0.0.11.82
- **Автор:** ДугДуг
- **Категория:** Стили и темы
- **Сайты:** `vk.com`

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`vk-dark.user.js`](./vk-dark.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
