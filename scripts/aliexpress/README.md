# AliExpress — таймер заказа

Подсчёт времени с дня оформления заказа на AliExpress.

- **Версия:** 2.2.2
- **Категория:** Утилиты
- **Сайты:** `aliexpress.com`

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`aliexpress.user.js`](./aliexpress.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
