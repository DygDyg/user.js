# Shikimori By TrackAnime

Добавляет кнопку перехода на сайт track-anime.dygdyg.ru

- **Версия:** 0.4
- **Категория:** Аниме
- **Сайты:** `shikimori.one`

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`shikimori-by-trackanime.user.js`](./shikimori-by-trackanime.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
