# Wowhead русификатор

## Назначение

Заменяет ссылки на Wowhead русскоязычными адресами ru.wowhead.com на посещаемых веб-страницах.


- **Версия:** 1.4
- **Автор:** ДугДуг
- **Категория:** Игры
- **Сайты:** `worldofwarcraft.com`, `ru.raider.io`

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`wowhead-rusifikator.user.js`](./wowhead-rusifikator.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
