# Discord Tool

## Назначение

Добавляет вспомогательную панель и команды для Discord: работу с названием канала, отправкой сообщений и переименованием диалога.


- **Версия:** 0.3
- **Автор:** ДугДуг
- **Категория:** Соцсети
- **Сайты:** `discord.com`

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`discord-utility.user.js`](./discord-utility.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
