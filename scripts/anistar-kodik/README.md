# Anistar kodik pleer

## Назначение

Добавляет на страницы Anistar и Online-Star видеоплеер Kodik и позволяет переключать вариант названия для поиска видео.


- **Версия:** 0.1
- **Автор:** ДугДуг
- **Категория:** Видео и плееры
- **Сайты:** `anistar.org`

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`anistar-kodik.user.js`](./anistar-kodik.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
