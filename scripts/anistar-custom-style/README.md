# Anistar custom style

Тема для сайта anistar

- **Версия:** 0.47.12
- **Автор:** ДугДуг
- **Категория:** Стили и темы
- **Сайты:** `anistar.org`, `online-star.org`

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`anistar-custom-style.user.js`](./anistar-custom-style.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
