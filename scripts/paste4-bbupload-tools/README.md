# Paste4 -> BBUpload tools

## Назначение

Находит ссылки BBUpload на Paste4, показывает сведения о файлах, выделяет качество 1080p и добавляет кнопки копирования и счётчики.


- **Версия:** 1.8
- **Автор:** ДугДуг
- **Автор в оригинальных метаданных:** не указан
- **Источник:** резервная копия Tampermonkey от 26 октября 2026 г.
- **Сайты/шаблоны:** `https://paste4.org/p/*`, `https://www.paste4.org/p/*`

[Установить userscript](https://raw.githubusercontent.com/DygDyg/user.js/main/scripts/paste4-bbupload-tools/paste4-bbupload-tools.user.js)

> Перенесено из резервной копии без проверки работоспособности на актуальных версиях сайтов. Автор для каталога изменён на ДугДуг; сведения об исходном авторе указаны выше. Ссылки обновления указывают на UserJS Hub.
