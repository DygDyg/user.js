# Кинопоиск Online (kodik)

Добавляет встроенный kodik-плеер для просмотра фильмов на Кинопоиске.

- **Версия:** 1.3
- **Категория:** Видео и плееры
- **Сайты:** `www.kinopoisk.ru`

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`kinopoisk-online.user.js`](./kinopoisk-online.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
