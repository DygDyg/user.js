# Raider.io русификатор

Переводит на русский описания предметов с Wowhead на raiders.io.

- **Версия:** 1.3
- **Автор:** ДугДуг
- **Категория:** Игры
- **Сайты:** `ru.raider.io`

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`ru-raider-io.user.js`](./ru-raider-io.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
