# VRChat Companion

## Назначение

Расширяет веб-интерфейс VRChat дополнительными инструментами для профиля, аватаров, избранного и навигации.


- **Версия:** 6.5
- **Категория:** Игры
- **Сайты:** `vrchat.com`

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`vrchat.user.js`](./vrchat.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
