# Analit

Внутренний скрипт аналитики DygDygWEB (экспериментальный).

- **Версия:** 1.0
- **Автор:** ДугДуг
- **Категория:** Инструменты разработчика
- **Действует на всех сайтах**

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`analit.user.js`](./analit.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
