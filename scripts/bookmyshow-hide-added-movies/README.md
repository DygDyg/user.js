# BookMyShow hide added movies + copy ID

Скрывает фильмы BookMyShow по ID + копирование

- **Версия:** 1.2
- **Автор в оригинальных метаданных:** не указан
- **Источник:** резервная копия Tampermonkey от 26 октября 2026 г.
- **Сайты/шаблоны:** `https://in.bookmyshow.com/explore/upcoming-movies-*`, `https://in.bookmyshow.com/explore/movies-*`

[Установить userscript](https://raw.githubusercontent.com/DygDyg/user.js/main/scripts/bookmyshow-hide-added-movies/bookmyshow-hide-added-movies.user.js)

> Перенесено из резервной копии без проверки работоспособности на актуальных версиях сайтов. Код и оригинальные метаданные автора сохранены, кроме ссылок обновления, указывающих теперь на UserJS Hub.
