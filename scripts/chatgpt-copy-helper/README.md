# ChatGPT [+..+] Copy Helper

## Назначение

Находит в ответах ChatGPT фрагменты в формате [+ ... +] и добавляет рядом кнопку для копирования их содержимого.


- **Версия:** 1.0.0
- **Автор:** ДугДуг
- **Автор в оригинальных метаданных:** you
- **Источник:** резервная копия Tampermonkey от 26 октября 2026 г.
- **Сайты/шаблоны:** `https://chatgpt.com/*`, `https://chat.openai.com/*`

[Установить userscript](https://raw.githubusercontent.com/DygDyg/user.js/main/scripts/chatgpt-copy-helper/chatgpt-copy-helper.user.js)

> Перенесено из резервной копии без проверки работоспособности на актуальных версиях сайтов. Автор для каталога изменён на ДугДуг; сведения об исходном авторе указаны выше. Ссылки обновления указывают на UserJS Hub.
