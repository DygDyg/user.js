# ChatGPT Widescreen Mode 🖥️

Enhances ChatGPT with wide/full/tall-screen + spamblock modes. Also works on perplexity.ai + poe.com!

- **Версия:** 2025.1.17.1
- **Автор в оригинальных метаданных:** Adam Lui
- **Источник:** резервная копия Tampermonkey от 26 октября 2026 г.
- **Сайты/шаблоны:** `*://chatgpt.com/*`, `*://chat.openai.com/*`, `*://*.perplexity.ai/*`, `*://poe.com/*`

[Установить userscript](https://raw.githubusercontent.com/DygDyg/user.js/main/scripts/chatgpt-widescreen-mode/chatgpt-widescreen-mode.user.js)

> Перенесено из резервной копии без проверки работоспособности на актуальных версиях сайтов. Код и оригинальные метаданные автора сохранены, кроме ссылок обновления, указывающих теперь на UserJS Hub.
