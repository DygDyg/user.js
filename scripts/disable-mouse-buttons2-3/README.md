# Отключить вперёд/назад

## Назначение

Пытается блокировать стандартные действия кнопок мыши «Назад» и «Вперёд» на веб-страницах, чтобы избежать случайной навигации.


- **Версия:** 2025-05-05
- **Автор:** ДугДуг
- **Категория:** Утилиты
- **Действует на всех сайтах**

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`disable-mouse-buttons2-3.user.js`](./disable-mouse-buttons2-3.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
