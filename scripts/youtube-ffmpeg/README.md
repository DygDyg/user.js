# YouTube FFmpeg Downloader

Скачивание и обрезка видео с YouTube через ffmpeg.wasm прямо в браузере.

- **Версия:** 1.2
- **Автор:** ДугДуг
- **Категория:** Загрузки
- **Сайты:** `www.youtube.com`

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`youtube-ffmpeg.user.js`](./youtube-ffmpeg.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
