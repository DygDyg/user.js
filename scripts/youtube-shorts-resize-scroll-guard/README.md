# YouTube Shorts Resize Scroll Guard

## Назначение

Предотвращает случайное переключение YouTube Shorts при изменении размера или переносе окна, сохраняя обычную прокрутку.


- **Версия:** 0.2.0
- **Автор:** ДугДуг
- **Автор в оригинальных метаданных:** не указан
- **Источник:** резервная копия Tampermonkey от 26 октября 2026 г.
- **Сайты/шаблоны:** `https://www.youtube.com/*`

[Установить userscript](https://raw.githubusercontent.com/DygDyg/user.js/main/scripts/youtube-shorts-resize-scroll-guard/youtube-shorts-resize-scroll-guard.user.js)

> Перенесено из резервной копии без проверки работоспособности на актуальных версиях сайтов. Автор для каталога изменён на ДугДуг; сведения об исходном авторе указаны выше. Ссылки обновления указывают на UserJS Hub.
