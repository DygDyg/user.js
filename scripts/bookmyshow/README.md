# BookMyShow — Movie Info Collector FIX

## Назначение

Собирает сведения о фильме на BookMyShow, включая описание, жанры, участников, длительность и изображения; обновляет данные при открытии панели.


- **Версия:** 1.8
- **Автор:** ДугДуг
- **Автор в оригинальных метаданных:** не указан
- **Источник:** резервная копия Tampermonkey от 26 октября 2026 г.
- **Сайты/шаблоны:** `https://in.bookmyshow.com/movies/*/*`

[Установить userscript](https://raw.githubusercontent.com/DygDyg/user.js/main/scripts/bookmyshow/bookmyshow.user.js)

> Перенесено из резервной копии без проверки работоспособности на актуальных версиях сайтов. Автор для каталога изменён на ДугДуг; сведения об исходном авторе указаны выше. Ссылки обновления указывают на UserJS Hub.
