# Hamster Kombat Clicker

## Назначение

Добавляет управление автоматическими нажатиями в Hamster Kombat и вспомогательные действия на странице игры.


- **Версия:** 2024-08-13-01
- **Автор:** ДугДуг
- **Категория:** Игры
- **Сайты:** `hamsterkombatgame.io`

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`hamsterkombatgame-clicker.user.js`](./hamsterkombatgame-clicker.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
