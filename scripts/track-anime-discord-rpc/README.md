# track-anime Discord RPC

## Назначение

Экспериментальная интеграция TrackAnime с активностью Discord через локальный WebSocket-сервис; в исходном коде отмечена как неактуальная.


- **Версия:** 0.2
- **Автор:** ДугДуг
- **Категория:** Аниме
- **Действует на всех сайтах**

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте [`track-anime-discord-rpc.user.js`](./track-anime-discord-rpc.user.js) и нажмите «Установить».

> Скрипт перенесён из архива [DygDyg/DygDygWEB](https://github.com/DygDyg/DygDygWEB/tree/master/user.js).
