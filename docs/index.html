    УСТАНОВКА

    Три шага — и сайт удобнее

    01

    Установи менеджер скриптов

    Одно расширение из магазина браузеров — и все скрипты ставятся в один клик, обновляются сами.

    • 🐵
      Tampermonkey Chrome Web Store ↗ Edge Add-ons ↗ Firefox Add-ons ↗
    • 🥷
      Violentmonkey Chrome Web Store ↗ Firefox Add-ons ↗

    Для Android с Chrome или Kiwi Browser — Tampermonkey из Chrome Web Store.

    02

    Выбери скрипт в каталоге

    Фильтруй по категориям, авторам и сайтам. Открой «Документацию» прямо на странице — описание, возможности и разрешения будут перед глазами.

    🔍📄🏷️
    03

    Нажми «Установить»

    Менеджер сам перехватит ссылку и покажет предпросмотр — подтверди установку. Дальше обновления приходят автоматически.

    ✅🔄⚡
    БраузерЧто установитьКак открыть магазин расширений
    Chrome / Яндекс / Edge / OperaTampermonkey или ViolentmonkeyСсылки на Chrome Web Store в шаге 01 (в Edge — Edge Add-ons)
    FirefoxTampermonkey или Violentmonkeyaddons.mozilla.org — поиск «userscript manager»
    Safari (macOS/iOS)Userscripts от Quark SoftwareApp Store → «Userscripts»; включите расширение в Настройки Safari
    Android (Kiwi / Chrome)TampermonkeyKiwi Browser совместим с расширениями Chrome

    Есть идея для скрипта?

    Репозиторий открыт для вкладов: форк, новый slug в scripts/, запись в scripts.json — и GitHub Actions сам опубликует обновлённый каталог.
